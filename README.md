# Virtual Casino & Sports Betting

## Projekto aprašymas

**Virtual Casino & Sports Betting** – edukacinė web aplikacija, skirta simuliuoti kazino žaidimus ir sporto lažybas naudojant tik **virtualius pinigus**.

Sistema leis vartotojams registruotis, valdyti virtualų balansą, atlikti sporto statymus bei žaisti kazino žaidimus.

> **Svarbu:** sistema nenaudoja realių pinigų ir nėra skirta realiems lošimams.

---

## Pagrindiniai funkcionalumai

### 1. Vartotojo paskyra

* Registracija ir prisijungimas
* Profilio peržiūra ir informacijos keitimas
* Virtualaus balanso peržiūra
* Virtualių tokenų papildymas

### 2. Sporto rungtynės ir lažybos

* Rungtynių ir komandų peržiūra
* Datos, laiko ir rezultatų rodymas
* Statymo tipo pasirinkimas
* Virtualaus statymo atlikimas
* Laimėjimo apskaičiavimas
* Duomenys gaunami iš TheSportsDB API

### 3. Bet Slip

* Kelių statymų pasirinkimas
* Pasirinktų statymų peržiūra
* Bendro koeficiento apskaičiavimas
* Galimo laimėjimo apskaičiavimas

### 4. Blackjack

* Kortų dalinimas
* Hit / Stand
* Win / Lose / Push
* Virtualus statymas

### 5. Dice

* OVER / UNDER / EXACT NUMBER
* Atsitiktinio rezultato generavimas
* Laimėjimo arba pralaimėjimo nustatymas
* Virtualaus balanso atnaujinimas

### 6. Ruletė

* Ruletės rato vizualizacija
* Skaičiaus arba spalvos pasirinkimas
* Atsitiktinio rezultato generavimas
* Laimėjimo apskaičiavimas

### 7. Istorija ir statistika

* Sporto statymų istorija
* Kazino žaidimų istorija
* Laimėjimų ir pralaimėjimų peržiūra
* Bendro pelno / nuostolio rodymas
* Balanso pokyčių grafikas

### 8. Atsakingas lošimas

* Statymų limitai
* Dienos arba savaitės limitų nustatymas
* Time-Out
* Self-Exclusion

### 9. Item Shop

* Virtualių tokenų naudojimas parduotuvėje
* Kosmetinių itemų pirkimas
* Avatarų rėmeliai
* Badge'ai
* Profilių temos
* Specialūs titulai

### 10. Referral sistema

* Unikalaus referral kodo generavimas
* Draugo pakvietimas naudojant referral kodą
* Bonusinių tokenų gavimas už pakviestą draugą
* Bonusas naujam vartotojui už referral kodo panaudojimą
